# Full House Research Project

Bidirectional Relationships Between Physical Activity and Weight Loss

## Project Overview

This repository contains R code for analyzing the relationships between physical activity and weight loss using data from the **All of Us Research Program**.

### Research Questions

1. Does weight loss increase physical activity? (mechanical unloading hypothesis)
2. Does physical activity increase weight loss? (behavioral hypothesis)
3. How do GLP-1 medication users compare to non-pharmacologic weight losers?

### Dataset

- **Dataset ID**: 06597753
- **Environment**: All of Us Secure Workbench (RStudio)
- **Important**: All data remains in the secure workbench and cannot be exported

## Data Quality Notes

### Weight Data
- Units converted to kg
- Plausibility bounds: 30-300 kg
- Same-day duplicates removed (first kept)

### Height Data
- Units converted to meters
- Plausibility bounds: 1.20-2.20 m
- Multiple measurements averaged

### BMI Data
- Computed from weight/height preferred over direct measurements
- Plausibility bounds: 12-80 kg/m²

### Fitbit Data
- Valid day criteria:
  - Steps: 100-50,000
  - Sedentary time: ≥180 minutes
  - Wear time: ≥600 minutes
- Analysis cohort requires ≥7 valid days

## Exclusion Criteria

Patients are excluded from analysis if they have:
- Bariatric surgery (any type)
- Both GLP-1 medication AND bariatric surgery
- Missing required data (BMI, Fitbit, age)
- Age outside 18-90 range
- BMI < 27 (for main analysis)
